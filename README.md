# Patrick Cagubcub — QA Portfolio

React + Vite portfolio foundation based on the supplied design reference.

## Run locally
Requires Node.js 18+.

```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## GitHub Pages
For a project repository, set `base` in `vite.config.js` to `'/YOUR-REPOSITORY-NAME/'`. For a `username.github.io` repository, use `/`. Configure GitHub Pages to deploy the `dist` folder using GitHub Actions.

Before publishing, replace the placeholder email, add your resume to `public/`, and review all project and employment details for confidentiality.
